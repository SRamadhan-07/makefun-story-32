# Tell a Whole Story in 32 Characters

A tiny Python program that writes a single Wi-Fi network name — a whole
funny story in 32 characters — to `/output/entry.txt`.

The name is: `Cat unplugged Dad's funeral Zoom`

A cat, a cable, and a funeral held over Zoom: a character, a disaster,
and an ending a passer-by can picture from a phone's network list.

## How to run

```bash
python3 main.py
```

This creates `/output` if needed and writes the entry text exactly to
`/output/entry.txt`, with no trailing newline.
